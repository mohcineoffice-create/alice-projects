# Alice Hub

A static chat page that talks to any OpenAI-compatible model provider (Gemini, DeepSeek, Mistral, ...) and can call MCP connectors as tools.

- Keys and connector URLs are stored only in your browser.
- Every tool call needs your manual approval; tool results are truncated and rendered as plain text.
- Live: [alice-hub.vercel.app](https://alice-hub.vercel.app)
